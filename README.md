# 🎬 Movie Ticket Booking System in Python

A simple, menu-driven **Movie Ticket Booking System** built using Python. This project allows users to book movie seats, view booked seats, cancel bookings, and search for existing reservations through a command-line interface.

## 📌 Features

- 🎟️ **Book a Seat:** Book a seat using your name and seat number.
- 📋 **View Booked Seats:** Display all currently booked seats and their owners.
- ❌ **Cancel Booking:** Cancel an existing seat reservation.
- 🔍 **Search Booking:** Check whether a particular seat is booked and view the customer's name.
- ⚠️ **Input Validation:** Handles invalid menu choices and unavailable bookings.
- 🚪 **Exit Application:** Exit the program safely.

## 🛠️ Technologies Used

- Dictionaries
- Functions
- Loops and Conditional Statements
- User Input and Output
